### Bug Fixes

- **Older LSS/VSS clients (v0.7.x–v0.8.x) get a full session again** — v0.9.0's compressed-columns protocol update dropped those clients to the legacy compatibility fallback: they stalled ~5 seconds on join and then ran the old degraded protocol-16 path. Servers now serve them natively — instant join and full-quality LOD streaming; the only feature they don't get is the new column compression, which their client can't decode. Affects both Fabric and Paper servers (including Folia, where server support remains experimental).

### Configuration

- **New `enableV18Compat` option (default on)** — the kill switch for the restored protocol-18 client support. Leave it on unless you need the strict version gate; with it off, v0.7.x–v0.8.x clients fall back to the legacy path as in v0.9.0. `/lsslod diag` shows a `V18Compat: clients=…` line whenever such clients have connected.
