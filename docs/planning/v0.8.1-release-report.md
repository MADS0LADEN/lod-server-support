     swapped, sky-dimension clears fill bright, level-floor clamp, cloned light arrays.

     `publishServer`; the shipped mixin pinned the 4-arg wrapper and never fired — "Open to
     LAN" ran without LOD since v0.6.0. Retargeted (bytecode-verified), construction hops
     to the server thread with a stopped-server guard, `LanHookContractTest` pins the
     descriptor (main-only file — must NOT ride a keep-ours merge onto support/**), and
     Tier 3's LAN gametest now publishes via the real GUI overload on every line.
   - M3: per-player `diskReadDone` grew monotonically all session; swept beyond the
     ingress radius + margin each eviction cycle (all players, in-pipeline/grace keeps,
     `trim()` because fastutil sets never shrink).
   - M4: router player order was identical every tick against the global disk-headroom
     gate — first player starved the rest under saturation; drain order rotates per cycle.
