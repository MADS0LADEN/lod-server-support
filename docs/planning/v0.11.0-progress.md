## Release-notes ledger (stage-accreted; stage F consolidates into the tag drafts)

- (A, Configuration) **`dirtyBroadcastIntervalSeconds: 0` now disables dirty
  broadcasts** — previously 0 clamped to 1 s, the fastest cadence. With 0, connected
  clients pick up terrain edits only on rejoin or their own re-requests; server-side
  freshness bookkeeping still runs, so rejoins always see current terrain.
- (A, Configuration) **`lodDistanceChunks` default 512 → 300** — the automatic
  timestamp-cache sizing follows the distance automatically.
- (B, Configuration) **`maxConcurrentDiskReads`** — new key (default auto): caps
  concurrent expensive region reads so server CPU stays bounded independently of
  bandwidth; store-served LODs are never throttled by it (auto = half the reader
  pool with the store on, no limit with it off). Raise bandwidth freely on
  store-heavy servers.
- (B, Performance) **Disk-read CPU is now bounded independently of bandwidth** —
  the disk-read concurrency gate headline (cold-region reads no longer turn a
  raised bandwidth cap into an unbounded CPU bill).
