## Release-notes ledger (stage-accreted; stage F consolidates into the tag drafts)

- (A, Configuration) **`dirtyBroadcastIntervalSeconds: 0` now disables dirty
  broadcasts** — previously 0 clamped to 1 s, the fastest cadence. With 0, connected
  clients pick up terrain edits only on rejoin or their own re-requests; server-side
  freshness bookkeeping still runs, so rejoins always see current terrain.
- (A, Configuration) **`lodDistanceChunks` default 512 → 300** — the automatic
  timestamp-cache sizing follows the distance automatically.
- (B, Configuration) **`maxConcurrentDiskReads`** — new key (default auto): caps
  concurrent expensive region reads so server CPU stays bounded independently of
  bandwidth; store-served LODs are never throttled by it (auto = half the reader
  pool with the store on, no limit with it off). Raise bandwidth freely on
  store-heavy servers.
- (B, Performance) **Disk-read CPU is now bounded independently of bandwidth** —
  the disk-read concurrency gate headline (cold-region reads no longer turn a
  raised bandwidth cap into an unbounded CPU bill).
- (C, New Features) **Runtime settings commands** — `/lsslod set <key> <value>`
  applies and persists config changes without a restart (distance, bandwidth
  caps, generation caps, dirty-broadcast interval, the disk-read gate);
  current-version clients pick up a distance change live, legacy clients on
  rejoin (a distance SHRINK leaves legacy clients re-asking beyond the new
  distance until rejoin — SET's required wording). `/lsslod help` (and bare
  `/lsslod`) lists every verb.
- (C, New Features) **Backfill remaining estimate** — `/lsslod store backfill
  status` now shows walked/total regions and a remaining columns estimate.
- (D, New Features) **`/lss reset` client command** — wipes Voxy's LOD store AND
  the LSS cache for the current server in one step: LODs visibly disappear, then
  rebuild live as the server re-streams everything. Without an active LSS session
  it requires `/lss reset confirm` (no server to re-stream from). Fabric client
  only; needs Voxy 0.2.18+ for the full effect (older Voxy: LSS half only, with
  a clear message).
- (D, Configuration) **Client cache moves to `.lss/`** — fresh installs keep the
  LSS column cache in a `.lss/` folder in the game directory (the `.voxy`
  convention); existing installs with `config/lss/cache/` keep using it, no
  migration needed.
