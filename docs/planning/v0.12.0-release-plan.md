## Phase A — land the stack on main

1. Merge **PR #207**: `gh pr merge 207 --merge --delete-branch`. **A stacked
   PR's base has THREE observed post-merge behaviors** (as-built): (a)
   retargeted to main, (b) still pointing at the dead base, (c) **CLOSED
   outright — the variant that actually fired** (2 s after #207's merge).
   Belt: check `gh pr view <stacked> --json state,baseRefName`. Variant (b)
   is fixable with `gh pr edit --base main`; variant (c) is recoverable ONLY
   by a NEW PR from the unchanged head branch (a closed PR whose base ref is
   gone cannot be reopened or retargeted) — the head SHA is untouched, so the
   recovery is provably lossless.
2. Merge **PR #208** the same way (`--merge`; never squash — the release-flow
   rule, and review records reference these SHAs).
3. Version bump on main: branch `chore/mod-version-0.12.0`, set
   `mod_version=0.12.0` in `gradle.properties`, PR → merge.
4. Post-merge sanity on main: `./gradlew :fabric:build -x runClientGameTest
   :paper:test :neoforge:build` + `python3 scripts/check_soak.py --selftest` —
   and confirm the merged main diff vs the pre-merge branch tip is empty
   (`git diff feat/region-summary-sync..main -- ':!gradle.properties'` after
   the bump) so the "which half landed" failure class is dead.
